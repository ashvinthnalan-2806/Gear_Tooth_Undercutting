# Labeled Dataset: Normal / No Undercut Gears

Place all photographs (.jpg, .jpeg, .png) of gears without undercutting (normal tooth profiles) into this directory.

### Requirements:
- Format: JPG, JPEG, or PNG
- Content: Close-up photographs showing healthy gear teeth with proper root fillets and involute profiles.
- Label: No Undercut (Negative Class, index 0)
